# Reproduction scope and file conventions

The public statistical cores preserve the original arithmetic. The layout
bootstrap, polynomial fits and Holm implementation are extracted unchanged.
The absolute-ratio adapter takes the already stored integer features instead
of recomputing them from full marginals. Paired correlations and the ordering
of distinct integer observations are preserved. The clean replay compares
all replicate arrays, point estimates, errors, fits and decisions.

## Compact observations

Each NPZ contains one array named observations and one row per independent
environment, in original block order. The layout columns are N, C1, C2, C4.
The absolute-ratio columns are N, 2LQ1, 2LQ2, 2LQ4, C1, C2, C4.
The integer Q representation is exact; floating Fourier roundoff was checked
when converting the original marginals. Original marginals are still
retained outside this repository and are reproducible from recorded seeds.
No resampling of the physical environments occurred during packaging.

The data manifest records dimensions, storage types, sample counts, hashes
and the largest conversion residual. Seed and block indexes distinguish
physical environment seeds from bootstrap seeds. A layout block concatenates
original batches of at most 250 environments; reusing only its first seed for
the whole block would be incorrect. The regeneration script preserves that
batch structure. Its default checks four original blocks, not four individual
environments.

## Original tests and auxiliary results

The original study's 30 decisions and all four rule/form fits per decision are
saved separately from the later stripe data. Second-cumulant and identity
results use their original sample schedule. A later fixed addition is used
only where specified. These summaries are not a fresh replay of the full
original collection.

The compact stripe arrays are sufficient for both primary analyses. They are
not sufficient for all auxiliary spatial spectra or third-order source
responses. Those outputs are preserved as summaries, with all relevant fits;
they must not be described as revalidated from these compact arrays.
The diagnostic-quarter data are likewise provided as analysis outputs rather
than all raw boundary observations.

## Numeric provenance

number_sources.csv lists scalar values and JSON pointers, including the
original complete fit records. Bootstrap arrays remain in the primary
outputs but are omitted from this human-auditable numeric index.
derived_values.json records algebraic spreads and ranges used in prose;
these do not constitute additional fits or changed decisions.
The README's key-result table is generated by looking up that numeric index.
The main tables read the same source values and are regenerated by verification.
The precision shown in prose is rounded; full precision is retained in JSON.
In the supplement's stripe tables, S/O/J mean standard/orthogonal/joint;
rN denotes the full-face variance ratio, r1/r2/r4 denote the one-/two-/four-
stripe variance ratios, raw1/raw2/raw4 denote fixed-mask rather than
orbit-averaged estimates, and delta41 is the four-minus-one contrast.
h1/h2/h4 are the corresponding third-cumulant ratios and hN the full-face
third-cumulant ratio. In the retrospective table, F is the return count,
N = C + F, D = C - F, r_D = Var(D)/E(N), cov_CF_over_N = Cov(C,F)/E(N),
and mean_imbalance = E(C-F)/E(N).
The paper's structural integers (dimension, model rule counts, equation
coefficients) are definitions or analytic quantities rather than measurements.
Version dates and citation years are bibliographic metadata.

source_manifest.json maps copied scientific inputs to their original relative
names and hashes. Unrelated private launchers were removed; the source
functions and allowed import/input adaptations are described per file.
release_manifest.json seals the delivered tree, excluding itself and local
Git metadata. Generated tables and figures are included in that seal.
The source mapping and file hashes do not independently establish historical
freeze dates.

## Implementation and mathematical checks

The exact port reduction was checked historically by finite-graph enumeration
and separate trajectory code. Counting identities, direct cyclic-window sums
and Fourier sums were also checked before this release. Those historical
checks are distinct from the release replay.

This release repeats the continuum kernel by numerical quadrature and the
stripe sum by a rational-period Hurwitz calculation independent of its
polylogarithm expression. The square bound covers only a Fourier tail.
The mixed-twist, microscopic source and two-loop calculations are reported
at their original scope; no new effective-field-theory computation was run
for publication.

The release checks ran in a new Windows environment with Python 3.12.10 and
the exact dependency versions in requirements.txt. CPU and elapsed times are
machine-specific. Other platforms and versions are not tested. A PDF rebuild
may have different metadata or pagination under another TeX distribution;
the numerical reproduction does not require LaTeX.
