# Version 1.0.0

**Partial ports and crossing fluctuations in the three-dimensional Lorentz mirror model**

JJIN HANZHE · 3 November 2026 · Research report, not peer reviewed

Pure retroreflection on part of a face reduces exactly, in each mirror
environment, to counting selected connections in a fully open reference
graph. Within established multiterminal diffusive counting theory, a
three-dimensional stripe calculation then predicts the variance-to-mean
ratio. Two independent data sets test the layout contrast and the absolute
half-open ratios under both microscopic rules and both prescribed
size extrapolations.

The release preserves all 3,668,750 stripe environments in compact form,
their original seed allocations, the complete 30-test report and all 120
original fits. The primary numerical replay matches the stored outputs.
The supplement includes the exploratory quarter-open excess and the
opposite third-cumulant deviations in independent batches. A complete
finite-size error bound remains open.

The two release attachments are the [paper](https://github.com/SHIN09-git/mirror3d-partial-ports/releases/download/v1.0.0/paper.pdf) and [supplement](https://github.com/SHIN09-git/mirror3d-partial-ports/releases/download/v1.0.0/sm.pdf).
The [source archive](https://github.com/SHIN09-git/mirror3d-partial-ports/archive/refs/tags/v1.0.0.zip)
contains the reproduction code, data, registrations, results and SHA-256 manifest.
