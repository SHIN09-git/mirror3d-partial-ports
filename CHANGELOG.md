# Changelog

## 1.0.0 — 3 November 2026

First public GitHub release of the research report and its reproduction
package. The version includes the paper and supplement, all 3,668,750 compact
stripe observations, registered plans, original seeds, analysis outputs and
scripts. Both PDFs link to this release. The repository preserves exact file
bytes on checkout so readers can verify the SHA-256 manifest.

## 1.0.0-rc1 — local candidate, 2026-11-01

Prepared an English report and supplement, all primary stripe environments,
fixed seed allocations, source hashes, numerical registry and reproduction
scripts. Preserved unfavorable fits and unresolved higher-cumulant tests.
Narrowed the novelty claim to the specific pure-retroreflection reduction,
three-dimensional stripe evaluation and numerical tests after identifying
prior two-dimensional boundary-connection counting.

This candidate was reviewed locally before the public release.
